Master key: set via masterKey (defaults to a weak dev value — change for prod).

Provider keys are read from the Secret: litellm-provider-secrets
Create it before use, e.g.:

  kubectl create secret generic litellm-provider-secrets -n {{ .Release.Namespace }} \
    --from-literal=OPENAI_API_KEY=sk-...

Reach the proxy in-cluster:
  http://litellm.{{ .Release.Namespace }}.svc.cluster.local:4000

Quick checks (port-forward, then use the master key):
  kubectl port-forward -n {{ .Release.Namespace }} svc/litellm 4000:4000
  curl http://localhost:4000/v1/models -H "Authorization: Bearer $MASTER_KEY"

Mint a per-tenant virtual key scoped to specific models:
  curl -X POST http://localhost:4000/key/generate \
    -H "Authorization: Bearer $MASTER_KEY" \
    -H "Content-Type: application/json" \
    -d '{"models": ["gpt-4o"], "metadata": {"team": "tenant-a"}}'
